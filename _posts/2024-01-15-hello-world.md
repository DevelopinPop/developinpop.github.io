This is your first blog post. It's just a regular **markdown** file sitting in the `_posts/` folder — no HTML required.

## Writing posts

Every post needs a filename in the form `YYYY-MM-DD-some-slug.md`, and a little front matter at the top:

```yaml
---
title: "Your Post Title"
date: 2024-01-15
tags: [meta, life]
---
```

Everything after the second `---` is normal Markdown: **bold**, _italics_, [links](https://example.com), lists, code blocks, images — all of it works.

- thing one
- thing two
- thing three

> Jekyll (and GitHub Pages) turns this file into a fully styled page automatically. Just commit and push.

That's it — no build step to run yourself, no JavaScript to write. GitHub does the building for you.
